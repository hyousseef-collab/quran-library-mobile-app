# المكتبة القرآنية

تطبيق ويب متجاوب (PWA) يضم:
- سور القرآن الكريم برواية ورش عن نافع
- تلاوة صوتية مباشرة
- أذكار وأدعية مع عدّ قابل للتنزيل
- تصميم يناسب الهواتف المحمولة

## التشغيل محلياً

1. افتح مجلد المشروع.
2. شغّل خادم محلي:

```bash
python3 -m http.server 8000
```

3. افتح المتصفح على:

```bash
http://localhost:8000
```

## التثبيت على الهاتف

- في Android: من المتصفح اختر “إضافة إلى الشاشة الرئيسية”.
- في iPhone: اختر “Add to Home Screen”.

## النشر

يمكنك نشر المشروع على:
- Netlify
- Vercel
- GitHub Pages
