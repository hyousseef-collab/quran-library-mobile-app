# المكتبة القرآنية

تطبيق ويب متجاوب (PWA) يقدم:
- سور القرآن الكريم برواية ورش عن نافع
- تلاوة صوتية من مصادر موثوقة
- أذكار وأدعية مع عدّ متحكم
- تصميم مناسب للهواتف Android و iPhone

## التشغيل محلياً

1. افتح المجلد على أي خادم ويب بسيط.
2. أو استخدم خادم محلي مثل:
   ```bash
   python -m http.server 8000
   ```
3. افتح المتصفح على:
   ```bash
   http://localhost:8000
   ```

## المزايا
- قابل للتثبيت على شاشة الهاتف كـ app
- يعمل كـ Progressive Web App
- مناسب للرفع لاحقاً إلى Capacitor

## الطريق التالي
- تحويل المشروع إلى Capacitor لبناء APK و IPA
- إضافة Splash Screen
- إضافة أيقونات تطبيق رسمية
- دعم المزيد من الروايات/الميزات
